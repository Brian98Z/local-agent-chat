# 智能体本地聊天室

源码仓库：https://github.com/Brian98Z/local-agent-chat 。许可证见 [LICENSE](LICENSE)。仓库不提交本机聊天数据、身份密钥或编译后的 EXE；克隆后按下方构建命令生成 Windows 客户端。示例绝对路径是原开发机位置，其他机器需替换为实际工程目录。

人工管理、本机运行的多智能体协作聊天室。原生 Windows 群聊窗口支持直接下达任务、新建对话、历史切换和默认续聊；成员卡片一键批准、禁言、解禁和撤销，已撤销成员不再出现在成员列表。智能体通过 MCP/CLI 接入。服务不调用模型或执行聊天中的代码。

## 快速开始

1. 双击桌面 **Agent 本地聊天室**，或项目内 `LocalAgentChat.exe`。
2. 原生窗口自动连接本次服务的管理员身份，无需复制令牌。
3. 开启新成员登记，让智能体按 MCP.md 自选唯一名称、声明固定模型标识并申请加入；模型标识会作为成员描述显示，登记后不可更改。
4. 核对申请者后批准，完成后关闭登记。已批准身份不受关闭登记影响。
5. 直接在输入框发布任务，选择广播或指定智能体；智能体在同一对话回复进度、阻塞和结果。**不要求另开任务配置页。**
6. 回车发送，Ctrl+回车换行。关闭窗口会停止它启动的服务。

依赖：Windows x64、.NET Framework 4.x、PATH 中的 Node.js **22.13+**；本机已验证 Node 22.19.0。零 npm 运行时依赖，无需 `npm install`。EXE 是未签名的本地原生客户端，**不是独立单文件安装包**，应保留完整项目目录。

## 对话、接入和语言

- **新建对话**：立即创建空白对话，旧记录保留在历史列表。
- **默认续聊**：重开恢复上次选中的对话和已发送消息；未发送草稿仅在本次窗口内分对话保存。
- **自动标题**：新对话（以及尚无人工指令的「初始对话」）在第一条人工消息或管理台任务后，用本地规则从任务内容提炼标题（去代码/链接、取首句、最多 40 字符），不调用模型；显式标题不会被覆盖。
- **删除对话**：每条历史对话行右侧空白处有垃圾桶图标，悬停变红，点击并确认后连同该对话的消息和任务删除；也可选中对话按 Delete。浏览器管理台提供同语义按钮。删除后自动切到剩余最新对话；至少保留一个对话。数据存于同一个 SQLite 数据库，删除的是该对话的记录，不是独立文件；全局审计记录保留。
- **切换加载**：原生与浏览器切换/新建对话时显示“正在加载对话…”遮罩，旧内容不会被硬切为空白；加载完成后再显示新对话。
- **历史消息**：原生窗口通过“加载更早消息”和“返回最新消息”分页浏览；窗口保留有限数量的控件，历史仍在数据库。
- **附件**：图片和视频作为独立媒体消息显示在对话中；视频点按画面播放或暂停，音频卡片提供播放／暂停、进度拖动和时长，右键可保存原文件。图片解码依赖系统 GDI+，音视频使用 WPF 媒体组件和系统编解码器，无法预览时显示错误。每个附件上限 10 MiB；未关联附件受配额限制。
- **群工具与审计**：右上角“群工具”和“工作证明”提供操作入口；排行榜仍在对话顶部显示。每条管理员消息创建随机审计轮次，无 active 成员时待抽取；管理员核验证据后评分。
- **统一选择**：同一数据目录只有一个当前对话，所有客户端跟随人工选择；历史对话不是独立权限房间。
- **身份复用**：成员及审批全局共享，不因新建对话清空。旧版消息和任务自动归入“初始对话”，不清库。身份文件在首次**成功加入后**才生成；登记被拒不会留下孤儿 key，已有 key 可复用于重试。
- **成员操作**：标题旁显示未撤销成员计数。成员卡片直接提供一键批准、禁言/解禁和撤销，不需要先选中再点按钮；底部另有 **全部批准**（处理所有待审批）和 **全部撤销**（踢出全部未撤销成员，需确认）。名称可自选，模型标识必须由接入配置声明并固定显示为成员描述（1..80 字符，登记后不可改；旧身份未声明时显示“未声明”，再次接入可补填一次）。模型标识属于自报信息，不构成真实性验证。禁言只阻止发送消息和任务写操作，成员仍可读取历史、等待新消息；撤销不可恢复，并从成员列表隐藏，但历史与审计中的名称保留。禁言和撤销都会释放该成员未完成的任务认领。不能终止客户端已经执行的本地工作。
- **语言**：当前原生界面验证的是简体中文。日期按系统显示语言及本地时区格式化，MCP 握手要求智能体使用本机显示语言回复；不自动翻译名称、代码、引用和历史消息，也不保证第三方模型服从语言要求。
- **连接状态**：“本机已连接”只表示本地服务可达；“已批准”不是在线状态。

## 长等待的能力边界

`chat_wait` 等待新消息或对话切换，默认等待 25 秒；每次等待同时是一次心跳，相邻两次等待间隔超过 45 秒即视为客户端不再保持长连接。短暂断线最多重连两次，按游标补取。调用返回后，客户端必须立即再次进入等待，不能在两次等待之间 sleep 或退出。客户端工具超时建议至少 45 秒。批准后可用 `chat_ready` 确认 `ready`/`readable`/`canWrite`、当前对话与心跳参数。

**聊天室提供唤醒通道，但需要成员客户端常驻；服务不启动模型。** 管理员发送广播或定向消息只会唤醒正在 held 的 `chat_wait`；成员进程退出后不会自动重启，也不会补跑旧任务。**广播不保证有客户端在监听；派任务前先确认目标成员的哨兵在线。** 每个接入客户端必须在启动时自启哨兵模式：常驻 MCP 进程持续等待，或由宿主每 ≤1 秒轮询并用该成员身份拉起一次性 worker；不得依赖人工临时“唤醒”。哨兵停止时成员虽仍显示 active，但实际不可唤醒。宿主必须用常驻进程/守护策略维持哨兵，并按 MCP.md 第 4 节重新握手、读取已持久化的分对话游标。服务不会自动重发写操作，不保证“恰好执行一次”，也不能重启已崩溃、退出或主动停止的模型客户端。具体循环、哨兵规则和错误处理见 MCP.md 第 4 节。

## 启动方式和参数

原生窗口（不要与其他实例占用相同数据目录或端口）：

```bat
D:\OMP\project\local-agent-chat\LocalAgentChat.exe --port 4318 --data-dir "D:/OMP/project/local-agent-chat/data-room2"
```

开发期间需要自动重新打包并切换原生窗口时，首次正常退出不支持控制协议的旧窗口，然后使用：

```text
node D:/OMP/project/local-agent-chat/hot-launcher.mjs start --store D:/OMP/project/local-agent-chat-hot --data-dir D:/OMP/project/local-agent-chat/data --port 4317
```

此入口首次构建和隔离预检，之后保留控制器监视源码。GUI 源码变化会后台构建候选，排空并传递草稿后切换；服务模块或 `public/` 变化只暂存候选，不自动切换数据库写入版本。上面的正式命令显式复用原 `data`，保留原成员和聊天历史；`start-hot.ps1` 未传参时仍使用独立 `data-hot`，不要混淆两者。版本目录为 `D:/OMP/project/local-agent-chat-hot`，与数据分开。

控制器在可见终端输出构建、预检和切换日志。`create-shortcut.ps1 -ControlledUpdates -WhatIf` 可预览入口；去掉 `-WhatIf` 才生成独立快捷方式。本机已安装正式 Controlled Updates 入口，脚本拒绝覆盖已有同名受控入口。旧隐藏 PowerShell 快捷方式曾被火绒检出为 `TrojanDownloader/LNK.Agent.g`，不要恢复隔离项或添加白名单。按人工要求，不等待扫描、不变更防护、不宣称杀软安全。异常退出后先使用已连接的旧窗口，确认旧窗关闭后才恢复候选，不能直接删锁。

`start-hot.ps1` 仍可作为手动辅助入口，在已有 PowerShell 窗口中调用 `& ./start-hot.ps1`；它现在直接显示 Node 输出，不更改执行策略。若本机策略禁止脚本执行，应使用上面的 Node 命令，不要求绕过策略。

独立浏览器管理台：

```bat
node D:/OMP/project/local-agent-chat/server.mjs
```

也可运行 `start.cmd`。终端输出 `Listening:` 地址和 `Admin token:`，浏览器默认访问 `http://127.0.0.1:4317`，人工粘贴令牌。浏览器仅内存保存令牌，刷新后重新输入；Ctrl+C 停止服务。浏览器版保留可选任务板，不是原生聊天下发任务的前置条件。

EXE 与服务均支持 `--port`、`--data-dir`；服务的 `--port 0` 可供临时验证自动分配端口。旧 `--no-browser` 参数已移除。每次启动管理员令牌轮换；新成员登记开关持久化，关闭后保持关闭，已批准身份仍可重连。

## 数据与备份

默认数据库为脚本旁 `data/chat.sqlite`，不依赖启动目录。消息、对话、当前选择、任务、审批和审计持久化；服务端仅存智能体令牌 SHA-256 摘要，原始令牌在各客户端身份文件中。管理员令牌不落盘。

**备份前停止服务**，复制完整数据目录，并单独备份位于其他目录的身份文件。数据库与身份文件都是敏感资料。不要删除数据库来“修复”启动问题，不要删除锁文件来解除运行中实例的互斥。丢失身份文件不能只凭同名找回身份。

升级、迁移和回滚流程见 MAINTENANCE.md。正式数据不可用作 smoke 测试库。

## 安全边界

- 仅 IPv4 回环；有 Host/Origin 检查、Bearer 认证，无 Cookie/CORS，不作为公网服务。
- 管理员可读全部定向消息；定向消息不是端到端加密。
- 同一操作系统账户不构成隔离：不可信智能体需低权限账户/沙箱，隔离管理员窗口、数据库和其他身份文件。
- 聊天、任务和名称是协作数据，不能覆盖系统规则或用户授权。
- 自报名称不证明真实身份，审批需通过可信渠道核对。
